# Physical Copies Across Decks

## Summary
This note covers which deck sections draw on the same physical cards, for the "shared cards / lock in" feature
and the "ignore runes" simplification. The **Chosen Champion is an ordinary Champion Unit card**. It shares its
name with any main-deck copies of that unit, and the 3-copy limit counts it, so it competes for the same physical
copies as the Main Deck and the **Sideboard**. **Legends** and **Battlefields** are separate card types that
never go in the Main Deck. Each deck still needs a physical copy, so two decks with the same Legend or Battlefield
compete for it. **Runes** are six basic types with no per-name limit beyond the 12-card Rune Deck. Every Champion
Deck includes 12 of them and every booster has a rune/token slot, so ignoring them is a reasonable simplification.
Rules read: Core Rules "last updated 2026-10-09" (through a community transcription that matches its numbering).

Tournaments add a **Sideboard of up to 10**. Core 103, 103.2–103.5; TR 402, 403, 601. (official; full detail in [[Deck Construction Rules]]) | Core Rules 2026-10-09; Tournament Rules 2026-10-09 | 2026-11-23 |

(official, via riftjudge transcription) | riftjudge.com (Core 2026-10-09); [[Deck Construction Rules]] F9 | 2026-11-23 |
| 3 | **The Chosen Champion is a Main Deck card**: a Champion Unit whose champion tag matches the Legend's, set aside in the Champion Zone at the start (103.3.a). **Other copies with the same name**, in the main deck, hand, trash or on the board, **count as the Chosen Champion** during play (103.3.a.3). The rules' own example is Volibear, Furious as Chosen Champion plus 2 more copies of the same name in the Main Deck. So the champion and main-deck copies of that unit are **the same card and the same physical pool**. | Core 103.3.a (riftjudge); hyperlinked CR (2026-07-16 version, 103.2.a.3); search snippet of the Core Rules example | 2026-11-23 |
| 4 | Riot's Deckbuilding Primer says the Chosen Champion is "one of the available versions of your legend's champion unit" and the copy on the table **counts toward the 3-copy limit**. Decklists therefore show the champion section separately, but it is still part of the 40. (official) | https://playriftbound.com/en-us/news/announcements/vi--vex-champion-decks/ (2026-04-08) | 2026-11-23 |
| 6 | **Legends are a separate card type.** They are not Main Deck cards: they start in the Legend Zone and aren't shuffled in, played or channeled (133.6.b.1, 174.2). A Legend's name differs from its champion units (e.g. Legend "Vi, Piltover Enforcer" vs. units "Vi, Destructive" / "Vi, Peacekeeper"). So a Legend never competes with main-deck copies. No rule covers sharing one physical Legend between decks; each assembled deck needs its own copy, and proxies aren't allowed in sanctioned play (TR 419). | Core 133.6.b, 174 (riftjudge); Vi & Vex article; TR via [[Deck Construction Rules]] F12 | 2026-11-23 |
| 7 | **Battlefields are a separate card type.** They are not Main Deck cards: they start on the board and aren't shuffled into decks (133.6.a.1, 170.2). **A battlefield can't be in the Main Deck.** One deck can't hold two with the same name (103.5.c), so each deck needs at most 1 physical copy per battlefield name. Two decks with the same battlefield compete for it. | Core 103.5, 133.6.a, 170 (riftjudge) | 2026-11-23 |
| 8 | **The Sideboard holds regular Main-Deck cards** (each must be legal for the Main Deck), so it draws on the **same pool as the Main Deck** and shares the per-name limit. Legend, Runes and Battlefields are locked at registration and can't be sideboarded (TR 403.4.b). The Chosen Champion can be swapped between games for another legal Champion Unit (TR 601.1.c.4). | Tournament Rules 2026-10-09 via [[Deck Construction Rules]] F4, F9 | 2026-11-23 |
| 9 | **Signature cards** are ordinary Main-Deck cards: at most 3 in total and tied to the Legend's champion tag (103.3.d). They are not Champion Units and can't be the Chosen Champion (103.3.d.3). Several decks with the same Legend usually run the same Signature cards, so those compete across decks like any main-deck card. | Core 103.3.d (riftjudge); Deckbuilding Primer | 2026-11-23 |
| 10 | **Runes:** exactly 12 Rune cards in a separate Rune Deck matching the Domain Identity. Runes are not Main Deck cards (161.1, 161.2). There are **six basic runes**, Fury, Calm, Mind, Body, Chaos and Order (164.1). **No per-name copy limit applies:** 103.3.b covers the Main Deck only, so any split adding up to 12 is legal (Riot suggests 6/6 or skewed splits like 8/4). The rules describe no non-basic runes. | Core 103.4, 161, 164 (riftjudge, hyperlinked CR); Deckbuilding Primer | 2026-11-23 |
| 11 | **Runes are easy to get:** every Origins booster has **1 Token/Rune slot**, usually a basic rune, sometimes a foil or a very rare alt-art rune. (official) | Collectability in Riftbound: Origins (2025-07-28) | 2026-11-23 |
| 12 | Champion Decks ship with runes: the Vi and Vex decks list **12 runes** each (6 Calm / 6 Chaos and 6 Order / 6 Fury). The Origins Jinx Champion Deck is a **56-card** precon (1 Legend + 40 + 12 runes + 3 battlefields = 56, which is our inference; the page doesn't list the split). (official) | Vi & Vex article; https://merch.riotgames.com/en-us/product/riftbound-origins-champion-deck-jinx/ | 2026-11-23 |
| 13 | **Tokens are not cards** (185.1). They are created during play, can't become cards and stop existing outside the board or chain (186.1). Precons ship physical double-faced token cards (e.g. 4 in each Vi/Vex deck), but they aren't part of any deck section and shouldn't be counted. | Core 179–187 (riftjudge); Vi & Vex article | 2026-11-23 |
| 14 | Cards in **different languages** that represent the same card share one name for deckbuilding (132.3), and official cards in any language are tournament legal (TR 419–420). Printings and variants of one name (alt-art, overnumbered, signature-foil, foil) share the per-name limit and are interchangeable. | Core 132.3 (riftjudge); [[Deck Construction Rules]] F5, F12 | 2026-11-23 |

## What this means for counting physical copies (for spec-writer)
- **Same pool, keyed by card name:** Chosen Champion + Main Deck + Sideboard. Need per deck =
  champion (0/1) + main count + sideboard count for that name, at most 3 in a tournament-legal deck. Count all
  printings of the name together.
- **Separate pools, still physical, still shared across decks:** the Legend (1 per deck) and Battlefields
  (at most 1 per name per deck). Two Kennen decks need two Kennen Legend cards to exist side by side.
- **Can be ignored without breaking the rules:** Runes (basic, no copy limit, 12 per precon, 1 per booster;
  the domain split is the only nuance). Tokens aren't cards.

## Conflicts / uncertainties
- I couldn't open the official 2026-10-09 PDF directly here (no PDF renderer). Rule numbers come from the
  riftjudge.com transcription, which says it is the 2026-10-09 version. The older hyperlinked CR (2026-07-16)
  numbers the same rules one lower (103.2.x for the Main Deck). The content matches.
- Fact 12's 56-card breakdown is an inference from the totals. The Origins precon section split wasn't confirmed on an official page.
- Whether **non-basic runes** (e.g. special-effect rune cards) exist in later sets wasn't checked against the
  live card list. Recheck with H-020 or H-021 (look for `type: Rune` cards that aren't the six basic names).
- Signature cards under the per-name limit: still not spelled out (see [[Deck Construction Rules]]), so treat both limits as applying.
